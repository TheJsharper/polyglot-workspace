# Local development demos

Recruiter demo tokens, the `/demo` page, and the ten-account sample dataset are available only when the backend runs in the local `dev` profile. Docker and the `prod` profile do not enable demo-token endpoints or seed sample accounts.

The token-generation, startup, test, and dataset details are kept in a local, Git-ignored `docs/dev/` guide. See [deployment.md](./deployment.md) for production requirements.
